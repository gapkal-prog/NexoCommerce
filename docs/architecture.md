# Architecture

## Product Model

NexoCommerce is designed as a dual-plugin architecture:

- Core plugin
- Pro plugin

## Goals

- Clean separation of responsibilities
- Modular services
- Private update capability
- Commercial licensing support
- Global-scale maintainability

## Monorepo Strategy

The repository contains:

- distributable WordPress plugins
- internal shared packages
- future cloud service code
- documentation and tooling

## Future Direction

Upcoming milestones will introduce:

- Core bootstrap kernel
- Pro bridge
- Licensing client
- Update client
- Elementor module system
- WooCommerce integration layer
