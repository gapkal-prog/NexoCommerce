# Licensing Strategy

NexoCommerce Pro will use a subscription-based licensing architecture.

## Principles

- Core and Pro are separate plugins
- Pro value is not based on a single local boolean
- Entitlements are resolved remotely
- Signed responses will be used in later milestones
- Private updates require valid access
- Grace period prevents store breakage

## Planned Features

- License activation/deactivation
- Site limits
- Staging detection
- Entitlement-based feature access
- Secure private update tokens
